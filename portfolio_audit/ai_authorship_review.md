# Authorship and AI-assistance review

**Inventory snapshot:** `35911fc63a1621f931aeaaa41ad632e28bf0ea72`

**Method:** Git tree/blob inventory plus project instructions, PR descriptions,
source headers, audit records and available local session-index search. No
authorship classifier or style-based inference was used.

## Findings

The record supports substantial ChatGPT/Codex involvement in technical
planning, implementation, debugging, test and tool automation, evidence
processing, and documentation. The project operating instructions explicitly
assign technical planning and execution responsibilities to these tools.
Merged PR descriptions #1–#6 also document AI-assisted work, including the
Gate-2 R-driver repair. This evidence rules out describing AI as a formatting-
only aid.

The available record does not establish a reliable human/model division by
file or line. Git author fields and commit timing are not treated as proof of
manual authorship. No contribution percentage is calculated. The register
classifies the engineering source set as AI-assisted at project level and marks
its per-file boundary as uncertain. Prompt and administrative files without
direct file-specific origin evidence remain `UNKNOWN`; raw simulation and tool
outputs are `TOOL_GENERATED`. No vendored third-party Fabric source was found in
the project notices/manifest review.

The local Codex session index search found no project-specific conversation
transcript. Repository prompts and task briefs are available, but they do not
constitute a complete interaction history. GitHub PR metadata for #1–#6 showed
no submitted review records. The archived patch reviews are separate Codex
contexts, not human reviews.

## Register

`generated/ai_provenance_register.csv` contains one row for each of the 1,265
tracked paths in the inventory snapshot, with its Git blob ID, conservative
origin category, available evidence, confidence and limitations. Regenerate it
for a chosen repository revision with:

```bash
python3 portfolio_audit/build_ai_provenance_register.py --revision 35911fc63a1621f931aeaaa41ad632e28bf0ea72
```

The register is a baseline snapshot, not a claim to include itself or other
files introduced by this review branch. This avoids a circular self-hash claim.
Files added by this review are plainly identified as Codex-assisted deliverables
in the branch history and this report.

At this snapshot the 1,265 rows classify as 284 `AI_ASSISTED_CONFIRMED`, 949
`TOOL_GENERATED`, and 32 `UNKNOWN`. There are no `HUMAN_CONFIRMED`,
`AI_GENERATED_CONFIRMED`, `MIXED_CONFIRMED`, or `THIRD_PARTY` rows: the evidence
does not support those stronger file-level conclusions. The assisted count is
project/source-set attribution, not 284 files proven to have been wholly
generated by an AI.
