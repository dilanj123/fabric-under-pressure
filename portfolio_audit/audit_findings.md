Baseline audited: `d2ef2bb2ec41a2b99f6532618a4a2d41bca736b5` (the exact Gate-5 public-ready commit). The inventory is generated by `build_register.py`; it reads that Git revision, calculates checkout SHA-256 and Git blob identities, records checkout status, and never executes repository content. It refuses a dirty checkout unless `--allow-worktree-differences` is explicitly supplied. The command used here was `python3 portfolio_audit/build_register.py --revision d2ef2bb2ec41a2b99f6532618a4a2d41bca736b5 --allow-worktree-differences`. The dirty check excludes only unstaged modifications and untracked files under `portfolio_audit/generated/`, so outputs can be regenerated; index-staged changes remain dirty and require the explicit flag. Other changes are recorded. Repeating the explicit command produced byte-identical CSV SHA-256 values. `generated/tracked_file_audit.csv` contains one KEEP/IMPROVE/ARCHIVE decision per baseline tracked file; `generated/raw_artifact_audit.csv` contains each tracked raw file; `generated/duplicate_groups.csv` records exact byte duplicates. `claim_evidence_matrix.csv` maps 20 public engineering claims to source and evidence; `frozen_baseline.json` records protected tag commits and hashes for RTL/formal/tests/benchmark inputs/processed results. Actions are marked as executed/not executed separately. The baseline-to-current worktree difference register contains 13 expected documentation/history path changes; none touches RTL, formal, workloads, benchmark data or raw results. Final independent review findings and fixes are in [`independent_review_pr1.md`](independent_review_pr1.md).

## Raw scanner findings

The gzip-aware raw scan found user-specific absolute path strings in 301 files. The initial email-shaped flags came from searching compressed bytes; after scanning decompressed content, none remained. The all-tracked-file credential-pattern scan reported zero matches in both raw and non-raw files. Two Gate-0 logs contain failure/error marker text; those logs are kept and their run intent must be interpreted from the corresponding summaries. The scan is pattern-based and is not a guarantee that every secret format is detected. The 301 user-specific path hits are raw logs from the qualified host; 19 runner scripts embed the same OSS CAD Suite location and are addressed separately in PR2.

The audit helper scans common private-key/token patterns but does not make a secret-detection guarantee. No detected value is written to this report. Raw evidence was not redacted or changed because that would alter its recorded hashes and provenance.
